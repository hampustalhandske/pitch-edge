# Module-level mutable containers in src/pitch_edge (vendor/ excluded), checked by
# tests/unit/test_module_state_census.py. One entry per line: <path relative to src/pitch_edge>::<name> | <reason>.
# A new entry needs a reason a fresh reader can check; a cache or registry says what it is keyed by and who writes it.

# Process caches and registries (written at run time)
dashboard/web.py::_ASK_CACHE | process cache: the dashboard's warehouse handle and `ask` graph, built once on first question and kept for the life of the server
research/summary.py::_RESEARCH_CACHE | process cache of the evidence summary keyed by ledger path, reused only while the ledger file's (mtime, size) is unchanged; guarded by _STATUS_LOCK
research/summary.py::_PAPER_CACHE | process cache of the paper status keyed by (ledger path, paper DB path), reused only while both files' (mtime, size) are unchanged; guarded by _STATUS_LOCK
paper/strategies.py::_REGISTRY | strategy id -> factory of the built-in paper strategies; never mutated, available_strategies() returns a copy
data/storage.py::TABLE_KEYS | table -> primary-key columns; lake/mirror.py adds the lake_* mirror tables at import, never mutated after import
research/devig.py::_FUNCS | de-vig method name -> function dispatch table, never mutated
research/devig.py::PARAM_NAMES | constant lookup table (method -> fitted parameter name), never mutated
